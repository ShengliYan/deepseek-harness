# Agent Note：模型选择器鱼形图标与窄容器 chip

Status: implemented

[English](2026-08-16-model-select-fish-glyph.md) | 中文

## 问题

输入栏里的模型 chip 只靠文字标签标识当前模型。在权限 chip 共用的 460px 输入栏宽度以下，标签省略到几乎不可读，窄窗口完全丢失模型控件的视觉标识，而相邻的权限 chip 仍然显示其图标。任何宽度下触发器也都没有图标，导致模型控件在图标开头的相邻控件旁只剩纯文本。

## 决策

模型选择触发器现在以 16px 的 `FishLogo` 开头，图标位于标签之前。460px 容器查询以下，chip 折叠为图标加箭头：标签与 effort 文本隐藏，完整模型名保留在 `aria-label`/`title` 与打开的菜单里。图标规则在窄查询之外隐藏图标，因此宽行保持此前纯文本外观、逐像素不变；容器查询与相邻 `PermissionSelect` 规则同理使用匿名查询，图标规则声明在其之前，让同优先级次序落在窄屏行为上。

## 备选方案

**保留标签并让它省略。** 否决：460px 及以下的省略标签不可读，且相邻 chip 已经确立了折叠为图标的模式。

**给触发器装饰开一个 slot。** 否决：为一个静态图标开契约 slot 是过度设计；将来若出现第二个消费方才需要这个座位，届时再加即可。

**把图标搬进共享原语。** 否决：`FishLogo` 已在 `dsh-client-ui-primitives` 中；本次改动是使用，不是新原语。

## 后果

宽输入栏行渲染与之前完全一致。窄行显示与权限 chip 一致的鱼形加箭头 chip，辅助技术读取完整模型名。改动是 CSS 加一个渲染图标：没有 API、契约或文案面。
